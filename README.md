# اتاق محتوای Quiz of Thrones

پنل مرورگری برای ورود گروهی ریلز، دانلود ویدیو و کاور و کپی کپشن. سرور Ubuntu 24.04، Nginx و Python؛ بدون Docker. اپ اندروید و اشتراک مستقیم از جریان فعلی کنار گذاشته شده‌اند.

## نصب اولیه

از هر مسیری که می‌خواهی:

```bash
git clone https://github.com/mhamze1994/instagram-reels-managment.git
cd instagram-reels-managment
sudo bash deploy/install-ubuntu.sh --configure-nginx
```

نصب اول فقط آدرس پنل مثل `http://SERVER-IP` را می‌پرسد. حساب‌ها ثابت‌اند: `user1` و `user2`، رمز هر دو `quiz1332`. تنظیمات قدیمی `PANEL_USER` و `PANEL_PASSWORD` و فایل حساب قبلی روی این دو حساب اثر ندارند. ورود از پنجرهٔ نام کاربری و رمز مرورگر انجام می‌شود.

کد به `/opt/quiz-studio` و داده‌ها به `/var/lib/quiz-studio` می‌روند. سرویس `quiz-studio` روی `127.0.0.1:8091` اجرا می‌شود. نصب‌کننده Python، venv، FFmpeg و فونت DejaVu را نصب می‌کند.

گزینهٔ `--configure-nginx` برای سرور اختصاصی با سایت پیش‌فرض است: از `/etc/nginx/nginx.conf` پشتیبان می‌گیرد و پیکربندی HTTP پورت ۸۰ را جایگزین می‌کند. در صورت وجود سایت نام‌دار یا TLS متوقف می‌شود. فایل‌های web root پاک نمی‌شوند. برای تغییرات عادی گزینه را دوباره نزن.

## به‌روزرسانی

داخل همان پوشهٔ clone:

```bash
git pull --ff-only
sudo bash deploy/install-ubuntu.sh
```

ویدیوها، وضعیت‌ها، رمز جدیدِ ثابت و اطلاعات کتابخانه در به‌روزرسانی حفظ می‌شوند؛ رمز قدیمی دیگر برای ورود استفاده نمی‌شود. سرویس خودکار restart می‌شود.

## کار روزانه

بالای کتابخانه «دسته‌بندی من» را انتخاب کن. انتخاب در localStorage همان مرورگر و به تفکیک حساب ذخیره می‌شود؛ پاک‌کردن داده‌های مرورگر آن را حذف می‌کند. دسته‌بندی ترجیح نمایش است و محدودیت دسترسی نیست.

دو تب وجود دارد: «در صف» با کارت بنفش و «منتشر شده» با کارت سبز. وضعیت‌های قدیمی `trial` نیز در منتشر شده دیده می‌شوند. منتشرشده‌ها بر اساس آخرین زمان ثبت انتشار، از جدید به قدیم مرتب‌اند.

هر کارت سه اقدام دارد: دانلود ویدیو، دانلود کاور، کپی کپشن. دانلودها لینک مستقیم با `Content-Disposition: attachment` هستند. برای کپی روی HTTP، روش `execCommand('copy')` هنگام کلیک استفاده می‌شود؛ اگر مرورگر کپی را نپذیرد، اقدام ثبت نمی‌شود و متن از جزئیات قابل انتخاب است. پذیرش کپی و محل ذخیرهٔ دانلود به مرورگر گوشی بستگی دارد.

سه اقدام به تفکیک کاربر در یک فایل کوچک `/var/lib/quiz-studio/download-actions.json` ذخیره می‌شوند. جدول یا دیتابیس جدیدی اضافه نشده است؛ کتابخانه از SQLite موجود استفاده می‌کند. با ثبت هر سه اقدام توسط یک کاربر، وضعیت موجود ویدیو `published` و زمان آن ثبت می‌شود. تکرار اقدام، زمان انتشار را جلو نمی‌اندازد. کلیک‌های دو حساب با هم ترکیب نمی‌شوند. این وضعیت برای پیگیری کار داخل ابزار است؛ به معنی اثبات انتشار روی Instagram نیست. لغو دانلود توسط مرورگر قابل تشخیص نیست.

کارت فعلی بعد از اقدام سوم جابه‌جا نمی‌شود؛ بستن جزئیات و برگشتن به صفحه هم فهرست را تازه نمی‌کند. با بارگذاری صفحه، دکمهٔ بارگذاری مجدد، تغییر تب/فیلتر یا دریافت دوبارهٔ فهرست، جابه‌جایی دیده می‌شود.

## تولید و پشتیبان

ورود چند فایل یا پوشه، ساخت از سه سؤال و JSON گروهی تا ۳۰۰ مجموعه حفظ شده است. AI انتخاب سؤال هنوز اضافه نشده است. قالب اصلی ۳۹ثانیه‌ای و میکس تأییدشده در `template` هستند. API key اختیاری بانک سؤال فقط در `.env` سرور نگه‌داری شود.

برای پشتیبان، سرویس را موقتاً متوقف کن یا از SQLite Backup API استفاده کن؛ فقط کپی فایل اصلی SQLite هنگام WAL کافی نیست. کل `/var/lib/quiz-studio` و `/opt/quiz-studio/.env` را حفظ کن. رمز یا فایل خصوصی را در Git نگذار.
