# Quiz of Thrones — اتاق محتوا

پنل شخصی برای نگهداری ویدیو، کاور و کپشن، بارگذاری گروهی، ثبت وضعیت انتشار و تولید ویدیو از سه سؤال با قالب تأییدشده. مناسب Ubuntu 24.04 LTS؛ بدون Docker.

## نصب از هر مسیر clone

```bash
git clone https://github.com/mhamze1994/instagram-reels-managment.git
cd instagram-reels-managment
sudo bash deploy/install-ubuntu.sh --configure-nginx
```

در نصب اول آدرس را مثل `http://SERVER-IP` وارد کن. نام کاربری `quiz` است؛ رمز را در ترمینال بدون نمایش وارد می‌کنی. رمز به‌صورت verifier هش‌شده ذخیره می‌شود. گزینهٔ `--configure-nginx` فقط برای سرور اختصاصی با سایت پیش‌فرض Nginx است: از تنظیم قبلی پشتیبان می‌گیرد، قبل از reload آن را تست می‌کند و اگر TLS یا سایت نام‌دار قبلی ببیند، تنظیم خودکار را متوقف می‌کند. فایل‌های `/usr/share/nginx/html` حذف یا تغییر نمی‌کنند.

اگر Nginx را می‌خواهی دستی تنظیم کنی، فلگ را حذف کن و از `deploy/nginx.conf.example` استفاده کن.

## آپدیت از همان پوشه

```bash
git pull --ff-only
sudo bash deploy/install-ubuntu.sh
```

کد اجرایی در `/opt/quiz-studio`، ویدیوها، SQLite و صف در `/var/lib/quiz-studio` قرار می‌گیرند. مسیر clone قابل تغییر است؛ نصب به آن وابسته نمی‌ماند. نصب مجدد تنظیم ورود و داده‌های قبلی را حفظ می‌کند. سرویس فقط یک worker دارد؛ رندرها به‌ترتیب اجرا می‌شوند. صف هنگام توقف سرویس محفوظ می‌ماند و کار قطع‌شده از ابتدا دوباره اجرا می‌شود.

```bash
systemctl status quiz-studio
journalctl -u quiz-studio -n 60 --no-pager
nginx -t
```

## قابلیت‌ها و وضعیت بررسی

- کتابخانهٔ صفحه‌بندی‌شده، جست‌وجو، فیلتر، کپشن قابل ویرایش و بایگانی برگشت‌پذیر.
- ورود MP4 با کاور و کپشن؛ پوشه‌های خروجی renderer را می‌توان گروهی وارد کرد. فایل تکراری با SHA-256 شناسایی می‌شود.
- بارگذاری هر ویدیو تا ۵۱۲ مگابایت؛ فایل‌های بزرگ‌تر پذیرفته نمی‌شوند.
- جست‌وجوی snapshot بانک سؤال؛ کلید API در مرورگر قرار نمی‌گیرد.
- صف پایدار تولید برای JSON شامل ۱ تا ۳۰۰ مجموعه؛ انتخاب خودکار با AI هنوز اضافه نشده است.
- قالب ۷۲۰×۱۵۶۰، ۶۰fps، سه سؤال، ۳۹ ثانیه؛ سؤال اول از فریم صفر کامل است، پاسخ سوم پنهان و معرفی بازی در ثانیهٔ ۲۴ است.
- یک رندر کامل از صف محلی به کتابخانه برگشته و decode آن توسط renderer بررسی شده است. تست‌های API شامل ورود، جلوگیری از تکرار، Range، دسترسی، صف ۳۰۰تایی و بازیابی کار قطع‌شده هستند.
- نصب واقعی Ubuntu/Nginx هنوز روی سرور کاربر اجرا نشده است.

### موبایل و اشتراک

**HTTP در مرورگر معمولی Clipboard و اشتراک مستقیم فایل را فراهم نمی‌کند.** روی HTTP می‌توان ویدیو و کاور را دانلود کرد. مسیر بومی اندروید در پوشهٔ `android` در حال توسعه است؛ APK نمونهٔ ابزار ساخت، نسخهٔ قابل‌استفادهٔ اپ نیست و در Git قرار نمی‌گیرد. نسخهٔ بومی نهایی قرار است همین پنل را نمایش دهد و اشتراک فایل و کپی را به اندروید بسپارد. تا زمان آزمون روی گوشی، تحویل به Instagram/Reels تأیید نشده است.

وقتی روی HTTPS باز شود، وب‌پنل از `navigator.share` و Clipboard استفاده می‌کند و قبل از اشتراک فایل را دریافت می‌کند. مقصد Reels و حالت Trial را خود اینستاگرام تعیین می‌کند. بازشدن منوی Share به معنای انتشار نیست؛ وضعیت باید بعد از انتشار ثبت شود. کاور مستقل ذخیره و در Instagram از گالری انتخاب می‌شود.

## بانک سؤال زنده

در `/opt/quiz-studio/.env` متغیر `QUIZ_API_KEY` را در خود سرور اضافه و سرویس را restart کن. کلید را در Git یا چت قرار نده. API client فقط به HTTPS همان مبدأ اجازهٔ ارسال کلید می‌دهد. snapshot فعلی برای جست‌وجوی اولیه همراه سورس است و خام تغییر نکرده است.

## قالب JSON تولید گروهی

نمونه در `batch-example.json` است. هر مجموعه دقیقاً سه سؤال و هر سؤال چهار گزینهٔ متفاوت دارد؛ `answer_index` از صفر شروع می‌شود. ۳۰۰ رندر فوری نیستند؛ سرعت به CPU سرور بستگی دارد و صف در پس‌زمینه اجرا می‌شود.

## پشتیبان

قبل از پشتیبان‌گیری فایل‌محور SQLite، سرویس را متوقف کن یا از SQLite Backup API استفاده کن؛ فقط کپی‌کردن فایل اصلی هنگام WAL فعال کافی نیست. `/var/lib/quiz-studio`، `/opt/quiz-studio/.env` و `/opt/quiz-studio/auth-defaults.json` را در پشتیبان خصوصی نگه دار. این موارد نباید وارد Git شوند.

## توسعه

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt httpx
PANEL_DEV=1 .venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8091 --workers 1
.venv/bin/python -m unittest discover -s tests -v
```

اگر ویدیوی نمونهٔ پروژه در دسترس نباشد، تست‌ها با FFmpeg یک fixture کوچک می‌سازند. سرویس تولید روی Linux به `ffmpeg` و فونت‌های داخل `template/assets/fonts` نیاز دارد. مجوز استفاده از فونت و میکس صوتی برای همان پروژهٔ شخصی کاربر در نظر گرفته شده است.
